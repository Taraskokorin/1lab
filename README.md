# CarExpenses

Тема: **Витрати на автомобіль** (додаток А, тема №14).

Застосунок допомагає власнику автомобіля вести облік витрат трьох видів —
заправка, обслуговування та штраф — і бачити, у що обходиться кожен
кілометр пробігу.

## Як запустити

```
cd CarExpenses
dotnet run
```
